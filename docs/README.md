# Documentation

Recommended reading order:

1. [Installation](INSTALLATION.md) for a clean host setup and qualification run.
2. [Workflow](WORKFLOW.md) for the two-phase execution lifecycle.
3. [Architecture](ARCHITECTURE.md) for process and package boundaries.
4. [Methodology](METHODOLOGY.md) and [Experimental Setup](EXPERIMENTAL_SETUP.md)
   for the research protocol.
5. [Measurement](MEASUREMENT.md) for timing, telemetry alignment, aggregation,
   and validity rules.
6. [Models and Devices](MODELS_AND_DEVICES.md) for adapter semantics and hardware
   profiles.
7. [Operations](OPERATIONS.md) for commands, resume behavior, and troubleshooting.
8. [Outputs](OUTPUTS.md) for prediction, summary, metadata, and log fields.

`PAPER_METHODOLOGY.tex` is manuscript-ready LaTeX. The accompanying BibTeX files
contain only references used by the methodology and ranking documentation.
